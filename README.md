# Portfólio Caio Augusto

**[caioaugusto-psi.vercel.app](https://caioaugusto-psi.vercel.app)** — portfólio em Astro, em português (`/`) e inglês (`/en/`). Estático: sem framework no cliente, sem CMS.

```
npm install
npm run dev      # desenvolvimento
npm run build    # gera dist/
npm run preview  # confere o build
```

Textos ficam em `src/i18n/`; projetos e imagens, em `src/data/work.ts` e `src/assets/img/`.
O currículo em PDF (PT e EN) está em `public/`.
